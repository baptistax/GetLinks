# GetLinks Privacy Policy

Last updated: July 10, 2026

GetLinks is a Chrome extension that helps users collect links from their currently open tabs for a site they choose.

## Information handled

After the user enters a site and clicks **Find links**, GetLinks reads the URLs of currently open browser tabs. A URL is web browsing activity and may contain personal or sensitive information.

GetLinks does not read page contents, cookies, form data, passwords, or the user's full browsing history. It does not scan tabs until the user starts a search.

## How information is used

Open-tab URLs are used only to find URLs whose hostname matches the site entered by the user. Matching URLs are deduplicated and displayed in the extension popup so the user can review, copy, or download them.

## Storage, retention, and sharing

All processing happens locally in the browser. GetLinks has no server and does not transmit, sell, share, or persist open-tab URLs or search input. Results remain only in the popup's temporary memory and are discarded when the popup closes or the search is reset.

If the user clicks **Copy links**, the matching URLs are written to the operating system clipboard. If the user clicks **Download .txt**, the browser saves a local text file. Both actions happen only at the user's request.

## Permissions

- `tabs` is used to read the URLs of currently open tabs after the user starts a search.
- `clipboardWrite` is used to copy matching URLs after the user clicks **Copy links**.

## Limited Use

GetLinks' use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide the extension's disclosed, user-facing purpose.

## Changes and contact

Material changes to this policy or to GetLinks' data handling will be disclosed before the changed behavior is used. For privacy questions, contact the developer through the support address published on the GetLinks Chrome Web Store listing.
